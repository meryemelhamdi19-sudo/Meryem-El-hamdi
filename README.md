## Merge conflict
si deux branches modifient la même ligne d'un même fichier avant le
merge  , on aura un merge conflict (qui parvient en générale lorsque deux modifications ne peuvent pas être fusionnées).Le merge conflict se résolut manuellement : les collaborateurs décident quelles modifications garder .

## Pull request
On utilise une Pull Request au lieu d'un push direct sur la branche principale pour que les changements apportés par un développeur soient examinées et approuvées par ses collaborateurs ou son supérieur , afin d'éviter l'insertion du code non vérifié qui pourra introduir des bugs ou des régressions.
